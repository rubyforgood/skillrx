What this decides

The app shell is the frame every SkillRx screen sits in: navigation, account, footer. It comes first because every other screen is built inside it. The Topics screen inside each option is the same in all three. It already follows the design system (one page header, one filter bar, a table with a caption, status pills), so you can judge the shell on its own.

Not decided here: what goes in each screen's table, row actions, the topic form, the sign-in page and the public home page. Each gets its own preview.

Why A: it matches Human Essentials, so volunteers who work on both apps find the same shell. It keeps the admin pages visible to administrators while giving contributors (who see only Topics and Beacons) the same layout. It also follows design.md's sidebar rules: icons on one level only, sentence case for group headers that are buttons, and the account pinned at the bottom.

What changes from today, whichever you pick

These follow from the design system's existing rules, so they aren't choices:

  • Emoji icons in the nav go. Today every link has an emoji. The rule is one icon set at one level of the hierarchy, or none.
  • "Log out" stops being a red button. Red means destructive, and signing out deletes nothing. It moves into the account menu and is renamed "Sign out", matching the sign-in page.
  • The fixed footer becomes an ordinary one. Today "Built with ❤️ by Ruby for Good" is pinned to the bottom of the window on every screen, taking 45px of height from every page, with a pulsing heart. It moves to the end of the page, where it shows once you scroll down.
  • Each page stops having its own color. Topics is purple, Users green, Regions green, the topic form dark blue, each with a gradient banner. The system's rule is one brand color, with other colors used only for meaning (success, warning, danger).
  • Filters fold behind a "Filters" toggle when a screen has more than two, as Topics (seven) does. Today the panel is always open and 547px tall, so on a 1280×800 screen the table starts at 875px, below the fold (measured 2026-11-24). The design system's filter bar shows one or two filters inline and folds the rest, so the table is the first thing on the page.
  • The font changes to Figtree, the design system's typeface, self-hosted.

Brand color

The design system ships indigo as its default brand color, but each app sets its own. Recommended: SkillRx's logo blue (#055889), so the nav, links, focus rings and primary buttons match the logo. It's 7.6:1 on white, so it passes WCAG AA for text. Use the toggle at the top to compare.
